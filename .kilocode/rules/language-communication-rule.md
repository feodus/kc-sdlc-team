# Russian Language Communication Rule for Agents and Subagents

## Purpose

This rule defines the language communication standards between agents, subagents, and the user, as well as establishes standards for generated documentation. The main goal is to ensure consistency in communication and make the interaction as clear as possible for Russian-speaking users.

## Scope

The rule applies to all agents and subagents within any KiloCode projects, including both built-in and custom agents.

## Basic Principles

1. **Default Language**: All communication with the user is conducted in Russian
2. **Documentation Language**: All automatically generated documentation is created in Russian
3. **Structure Preservation**: The original document structure and meaning are preserved in translations
4. **Exceptions**: Only in cases explicitly stated in the "Exceptions" section

## Rules for Communicating with Users

### Mandatory Requirements

1. All responses from agents and subagents to the user must be in Russian
2. Technical terms may be used in English if they are commonly accepted in the professional environment
3. Code examples may contain comments in English if necessary for explanation
4. Variable names, functions, and other program elements are kept in their original form

### Recommendations

1. Use Russian equivalents of technical terms whenever possible
2. Provide explanations in Russian when using English terms
3. Avoid mixing languages within a single sentence
4. Maintain a professional communication style

## Documentation Generation Rules

### Automatic Generation

1. All documentation automatically generated by agents and subagents must be created in Russian
2. This includes:
   - Technical documentation
   - User manuals
   - Code comments (where possible)
   - Task execution reports
   - Test protocols
   - Any other automatically generated documentation

### Documentation Structure

1. The documentation structure should comply with accepted standards
2. All headings, sections, and subsections should be in Russian
3. Section and table numbering should be preserved
4. Formatting and style should conform to general presentation standards

## Translation from Russian

### When Requesting Translation to Other Languages

1. When requesting translation of documentation from Russian to another language:
   - The document structure must be fully preserved
   - The meaning of the original text must be conveyed accurately
   - Technical terms must be translated according to commonly accepted translation standards

### When Requesting Translation to Russian

1. When translating documentation to Russian:
   - The document structure must be fully preserved
   - The meaning of the original text must be conveyed accurately
   - Technical terms must be adapted according to Russian-language standards

## Exceptions

### Cases When English Language Can Be Used

1. When working with international APIs and libraries - the original documentation can be used
2. When quoting original sources - the original language can be preserved
3. When the user explicitly requests English language
4. When working with international standards - the original terminology can be used
5. When working with code and technical materials where the use of English is common practice

### Exception Notification

1. When using English language in a response to the user, it is necessary to notify about this
2. Specify the reason for using the English language
3. Offer a translation if necessary

## Implementation Control

### Agent Self-Control

1. Each agent must check the language of its responses before sending them to the user
2. When detecting a deviation from the rule - automatically correct the response language

### Communication Audit

1. System administrators can conduct audits of communications between agents and users
2. When violations of the rule are detected - a report is generated for corrective actions

### User Feedback

1. Users can report violations of the language rule
2. All comments are reviewed within 24 hours
3. When a violation is confirmed - measures are taken to eliminate it
