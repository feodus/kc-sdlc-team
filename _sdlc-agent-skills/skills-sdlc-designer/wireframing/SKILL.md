# Wireframing

> **Meta:** v1.0.0 | 06-04-2026

## Purpose

Skill for creating wireframes - simplified interface diagrams without visual details. Includes structure, layout, and information architecture.

## When to Use

Use this skill:
- When designing new screens
- For validating layout before design
- When working with stakeholders
- For low-fidelity usability testing
- When documenting requirements
- For rapid iteration

## Wireframe Types

### Low-fidelity

- Quick sketches
- Paper or simple tools
- Basic blocks
- No details

### Mid-fidelity

- Digital tools
- Basic typography
- Simple UI elements
- Basic navigation

### High-fidelity

- Detailed mockups
- Real components
- Basic typography
- Interactive elements

## Best Practices

### Structure

```
1. Start with content - structure matters more than decoration
2. Use consistent components - repeat elements
3. Include all states - show all states
4. Add annotations - document decisions
5. Test with users - validate with users
```

### Annotations

```markdown
# Wireframe Annotations

## Header
- Logo: Left aligned
- Search: Expandable on focus
- User: Dropdown menu on click

## Sidebar
- Width: 240px fixed
- Collapse to icons on mobile
```

## Testing with Wireframes

### Usability Test

```
1. Show wireframe to user
2. Ask them to complete a task
3. Observe difficulties
4. Record questions
5. Debrief and optimize
```

### Stakeholder Review

```
1. Show wireframe
2. Ask for feedback
3. Document comments
4. Prioritize changes
```

## Quality Criteria
