# User Research

> **Meta:** v1.0.0 | 06-04-2026

## Purpose

Skill for conducting user research. Includes interviews, observation, data analysis, and insight synthesis.

## When to Use

Use this skill:
- When researching users of a new product
- For understanding user needs and pain points
- When conducting stakeholder interviews
- For creating user personas
- During usability testing
- For validating design decisions

## Research Methods

### Quantitative

| Method | Description | When to Use |
|-------|-------------|------------|
| Survey | Online surveys | Large sample |
| Analytics | Behavior analysis | Understanding patterns |
| A/B Testing | Comparing variants | Optimization |

### Qualitative

| Method | Description | When to Use |
|-------|-------------|------------|
| Interviews | In-depth interviews | Understanding motivation |
| Focus groups | Group discussions | Idea generation |
| Observation | Observation | Usage context |
| Diary study | Diary entries | Long-term usage |

## Interviews

### Preparation

```
1. DEFINE research goal
2. CREATE questions
3. FIND respondents
4. PREPARE materials
```

### Questions

```markdown
## Opening
- Tell me about yourself
- How do you use [product] at work?

## Pain points
- Describe a problem you face
- How do you solve it now?

## Workflow
- Describe your typical workday
- What tools do you use?

## Closing
- What would you like to change?
- Any questions?
```

## Observation Studies

### Observation Tasks

```
1. Observe real usage
2. Record actions
3. Note difficulties
4. Document context
```

### Observation Template

```markdown

- Experience level: [Level]
```
