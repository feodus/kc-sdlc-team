# Organizational Change Management

> **Meta:** v2.0.0 | 09-03-2026
> **Renamed from:** change-management

## Purpose

Organizational change management is a systematic approach to preparing, implementing, and solidifying changes at the organizational level. Unlike managing change requests within a project (change-request), this skill focuses on organizational transformation: implementing new processes, restructuring, changing corporate culture, and adapting employees to new working conditions.

Used for successful organizational change implementation with minimizing resistance and maximizing employee adoption.

## When to Use

Use this skill:
- When implementing new processes or development methodologies
- When restructuring a team or department
- When transitioning to new technologies or tools
- When merging or acquiring companies
- When changing corporate culture
- When implementing large digital transformation projects
- When managing change resistance

**Important:** For managing changes within a project (change requests, impact assessment) use the [`change-request`](change-request/SKILL.md) skill.

## Change Management Models

### ADKAR Model

ADKAR model (ProSci) includes five sequential stages:

| Stage | Description | Actions |
|------|-------------|----------|
| **Awareness** | Creating understanding of need for change | Communications, meetings, demonstrating problems |
| **Desire** | Forming desire to participate and support change | Motivation, demonstrating benefits, working with leaders |
| **Knowledge** | Providing knowledge on how to implement change | Training, workshops, documentation |
| **Ability** | Developing skills and abilities to apply knowledge | Practice, mentoring, support |
| **Reinforcement** | Maintaining changes through encouragement and recognition | Metrics, feedback, rewards |

### Kotter's 8-Step Model

Kotter's model includes eight steps:

1. **Creating urgency** — demonstrating need for change
2. **Forming guiding coalition** — creating change leader team
3. **Forming vision and strategy** — defining future state
4. **Communicating vision** — spreading information about changes
5. **Empowering action** — removing obstacles, empowering
6. **Creating short-term wins** — achieving visible results
7. **Consolidating changes** — strengthening achieved results
8. **Anchoring in culture** — integrating changes into norms

## Functions

### 1. Current State Analysis

Assessing organizational readiness for change:
- Analyzing current processes and practices
- Assessing cultural context
- Identifying stakeholders and their influence
- Determining potential resistance points
- Assessing resources and capabilities

### 2. Change Planning

Developing change management strategy:
- Defining change scope and goals
- Selecting appropriate management model (ADKAR, Kotter)
- Developing communication plan
- Planning training and development
- Defining success metrics

### 3. Stakeholder Management

Effective engagement with interested parties:
- Identifying key stakeholders
- Analyzing influence and interests
- Developing engagement strategy
- Regular communications
- Addressing objections

### 4. Resistance Management

Overcoming resistance to change:
- Identifying sources of resistance
- Applying resistance handling techniques
- Involving opinion leaders
- Creating safe space for feedback
- Phased implementation

### 5. Change Communication

Effectively informing about changes:
- Developing communication strategy
- Creating key messages
- Selecting communication channels
- Regular updates
- Feedback and two-way communication

### 6. Training and Development

Preparing personnel for new conditions:
- Identifying training needs
- Developing training programs
- Conducting workshops
- Creating materials and documentation
- Mentoring and support

### 7. Monitoring and Adjustment

Tracking progress and making adjustments:
- Tracking metrics for each ADKAR stage
- Regular surveys and assessments
- Analyzing feedback
- Adjusting plan
- Managing change risks

## Usage Examples

### Example 1: Implementing Agile Methodology

Situation: Company transitioning to Agile development approach.

ADKAR Plan:
- **Awareness:** Presentations on Agile benefits, demonstrating problems of current approach
- **Desire:** Team involvement in piloting, demonstrating early successes
- **Knowledge:** Training on Scrum/Kanban, Pair programming, tools training
- **Ability:** Mentoring, retrospectives, ongoing support
- **Reinforcement:** Team metrics, recognition, integration into performance review

Success Metrics:
- Velocity stabilized
- Sprint burndown maintained
- Team satisfaction > 4/5
- Time-to-market reduced by 30%

### Example 2: Implementing New CRM System

Implementation Plan:
1. Coalition formation: Sponsors (management), Champions (opinion leaders), Agents (internal trainers)
2. Communications: Town halls, emails, FAQ, intranet portal
3. Training: Tiered approach (administrators → power users → end users)
4. Support: Help desk, champions network, knowledge base

Resistance Management:
- Working with opinion leaders early
- Demonstrating benefits for each role
- Phased rollout
- Quick wins and successes

### Example 3: Team Restructuring

Situation: Merging two development departments.

Stages:
1. Analysis: Audit both teams, identifying cultural differences
2. Planning: Defining new structure, roles, processes
3. Communication: Transparent informing about reasons and plans
4. Integration: Joint activities, team building
5. Reinforcement: New norms, values, processes

Risks and Mitigation:
- Resistance → Working with leaders, transparency
- Losing key employees → Retention bonuses, career paths
- Cultural conflict → Forming shared values

## Organizational Change Metrics

### ADKAR Metrics

| Stage | Metric | Target Value |
|------|---------|------------------|
| Awareness | % aware of need for change | > 90% |
| Desire | % willing to support change | > 75% |
| Knowledge | % completed training | 100% |
| Ability | % able to apply knowledge | > 85% |
| Reinforcement | % solidified changes | > 80% |

### Organizational Metrics

- Employee engagement score
- Adoption rate of new processes
- Time to productivity
- Change resistance incidents
- Stakeholder satisfaction

## Common Mistakes

1. **Skipping ADKAR stages** — change doesn't stick
2. **Insufficient communication** — rumors and misunderstanding
3. **Ignoring resistance** — conflicts and change failure
4. **No quick wins** — momentum loss
5. **Insufficient reinforcement** — return to old ways
