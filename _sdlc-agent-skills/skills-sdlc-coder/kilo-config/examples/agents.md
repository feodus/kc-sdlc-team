# AGENTS.md — Пример

Положи этот файл в корень проекта.

```markdown
# My Project

Краткое описание проекта для AI агентов.

## Code Style

- Используй TypeScript для всех новых файлов
- Следуй ESLint конфигурации проекта
- Используй 2 пробела для отступов
- Все функции должны иметь типы

## Architecture

- Следуй MVC паттерну
- Компоненты React не более 200 строк
- Используй dependency injection
- API endpoints в `/src/api/`

## Testing

- Пиши юнит-тесты для бизнес-логики
- Минимальное покрытие: 80%
- Используй Jest и React Testing Library
- Тесты рядом с компонентом: `Component.tsx` → `Component.test.tsx`

## Security

- Никогда не коммить API ключи или секреты
- Валидируй все пользовательские входные данные
- Используй параметризованные запросы к БД
- XSS защита через sanitize

## Git Workflow

- Коммиты по Conventional Commits
- Ветка `main` защищена
- PR через `feature/` или `fix/` ветки

## Best Practices

- Be specific and clear — Конкретные правила, не "пиши хороший код"
- Включай примеры — Показывай паттерны
- Организуй по категориям — Группируй связанное
- Keep it concise — Короткие предложения
- Обновляй регулярно — Пересматривай по мере развития
```

### Размещение

```
my-project/
├── AGENTS.md          # В корне проекта
├── src/
├── package.json
└── ...
```

### Важно

- Имя файла **должно** быть `AGENTS.md` (верхний регистр)
- Файл защищён от изменений агентом без подтверждения
- Работает вместе с другими источниками инструкций
