# Minimal Skill Template

Шаблон для создания базового навыка (skill).

```yaml
---
name: my-skill-name
description: Краткое описание что делает навык и когда его использовать
---

# My Skill Name

## Когда использовать

Используй этот навык когда [конкретный триггер].

## Инструкции

1. [Шаг 1]
2. [Шаг 2]
3. [Шаг 3]

## Примеры

### Пример 1

Вход: [описание входа]
Выход: [описание выхода]
```

### Параметры

| Поле | Обязательно | Описание |
|------|-------------|----------|
| name | Да | Должно совпадать с именем папки |
| description | Да | Макс 1024 символа |

### Правило имени

```
✅ skills/my-skill-name/SKILL.md     # name: my-skill-name
❌ skills/my-skill-name/SKILL.md   # name: wrong-name
```
