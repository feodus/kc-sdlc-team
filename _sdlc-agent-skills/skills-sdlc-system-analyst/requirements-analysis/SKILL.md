# Инструкции

1. **Собрать требования**: Провести интервью с стейкхолдерами, провести опросы, наблюдать за процессами.
2. **Документировать BRD**: Создать Business Requirements Document с четкими условиями, ограничениями и целями.
3. **Провести анализ стейкхолдеров**: Классифицировать стейкхолдеров по влиянию и интересу, выделить ключевые вопросы.
4. **Валидировать требования**: Проверить полноту и согласованность требований с помощью методов INVEST/INVEST как темплейт.

# Примеры использования
- Обновление требований для e-commerce системы
- Создание BRD для мобильного приложения
explorer = sdlc-system-analyst
