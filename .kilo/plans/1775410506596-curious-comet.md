# План: Конвертация TG-Bot-Expert в навык для sdlc-coder

## Цель
Преобразовать агента `@tg_bot_expert` в навык (skill) для агента `@sdlc-coder`

## Анализ текущего состояния

### Существующие компоненты
- `tg_bot_expert/ENG/TG-Bot-Expert.yaml` — конфигурация режима
- `tg_bot_expert/ENG/telegram-bot-standards.md` — стандарты разработки
- `sdlc-coder/skills-sdlc-coder/telegram-bot-development/SKILL.md` — уже существующий навык

### Вывод
Навык `telegram-bot-development` уже существует и очень подробный (500+ строк). STANDARDS из TG-Bot-Expert частично дублируются, но имеют дополнительные детали по GitLab CI/CD.

## План работ

### Этап 1: Обновление навыка telegram-bot-development
Обогатить существующий SKILL.md дополнительными деталями из TG-Bot-Expert:
- Добавить секцию "Thinking Algorithm" (Chain of Thought)
- Добавить технические директивы для Docker/GitLab CI/CD
- Добавить секцию "Strict Prohibitions"
- Добавить информацию о коммуникационном стиле

### Этап 2: Перемещение стандартов
Переместить `telegram-bot-standards.md` в папку навыка для справки:
- Источник: `tg_bot_expert/ENG/telegram-bot-standards.md`
- Цель: `sdlc-coder/skills-sdlc-coder/telegram-bot-development/STANDARDS.md`

### Этап 3: Обновление документации
Обновить AGENTS.md:
- Удалить TG-Bot-Expert из списка режимов
- Добавить информацию о навыке telegram-bot-development в секцию "Доступные навыки Universal Coding Agent"

### Этап 4: Удаление старой директории
Удалить папку `tg_bot_expert/` после миграции

## Критерии завершения
- [ ] Навык telegram-bot-development обновлён
- [ ] STANDARDS.md перемещён в папку навыка
- [ ] AGENTS.md обновлён
- [ ] Папка tg_bot_expert удалена
